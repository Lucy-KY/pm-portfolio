# pm-portfolio
A curated product management portfolio showcasing end-to-end PM skills across real coursework, case studies, and project deliverables.
This repository transforms academic assignments and practical exercises into industry-ready PM artifacts — including PRDs, user stories, journey maps, data strategy briefs, financial models, and go-to-market analyses.

It highlights my approach to product thinking, problem-solving frameworks, and cross-functional collaboration, presenting a cohesive body of work that reflects my capabilities as a product manager in both technical and business-driven environments.

**Contents include:**

* 📌 Case-based PM artifacts rewritten from real coursework during my Master study

* 🧩 User stories, acceptance criteria (INVEST), workflows & wireframes

* 📊 Market sizing, competitive analysis, and product strategy decks

* 🗃️ Data governance & analytics deliverables adapted into PM use cases

* 💰 Financial modeling (ROI, NPV, payback) for product decisions

* 🚀 End-to-end product case studies showing problem → insights → solution → metrics

This portfolio is continuously updated as I refine past work and add new case studies.
